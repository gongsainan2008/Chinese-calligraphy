# 书法练习网站 MVP 需求文档

**版本：** v1.0  
**日期：** 2026-03-22  
**状态：** 初稿

---

## 1. 产品定位

面向书法初学者的在线临摹练习工具，帮助用户通过对比练习提升书写水平。

## 2. 目标用户

- 书法零基础或入门级爱好者
- 想利用碎片时间练字的人群
- 线下学书法的学生（辅助练习）

---

## 3. MVP 功能清单

### 3.1 核心功能（必须做）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| **字帖选择** | 内置 10-20 张经典楷书字帖缩略图，用户点击选择 | P0 |
| **临摹练习** | 字帖作为底层，上覆透明画布，用户书写 | P0 |
| **擦除重写** | 一键清除当前书写，不影响底图 | P0 |
| **保存作品** | 将练习结果保存为图片到本地 | P0 |

### 3.2 扩展功能（可选）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| **笔画粗细调节** | 调整画笔粗细（3档：细/中/粗） | P1 |
| **颜色选择** | 练习墨色选择（黑/红/蓝） | P1 |
| **字号调整** | 缩放底图大小 | P1 |
| **历史记录** | 本地保存最近 5 份练习记录 | P2 |

---

## 4. 页面结构

```
首页
├── 字帖列表（网格展示）
│   └── 练习页面（临摹台）
│       ├── 工具栏（笔触粗细、颜色、擦除、保存）
│       ├── 字帖层（底层）
│       └── 书写层（透明Canvas）
└── 关于/使用说明（弹窗或新页面）
```

---

## 5. 技术方案

### 5.1 技术栈

| 层级 | 技术选型 | 理由 |
|------|----------|------|
| 前端框架 | Vue 3 + Vite | 轻量、开发快 |
| 绘图 | HTML5 Canvas | 原生支持，无需额外库 |
| 样式 | Tailwind CSS | 快速构建 UI |
| 部署 | Vercel / Netlify | 免费、CDN 加速 |

### 5.2 关键实现

**双层 Canvas 架构：**
```
┌─────────────────────┐
│   书写层 (Canvas)   │  ← 用户书写，透明背景
├─────────────────────┤
│   字帖层 (Img)      │  ← 经典碑帖图片
└─────────────────────┘
```

**保存作品：** 将两层合并为一张图片，使用 `canvas.toDataURL()`

---

## 6. 数据需求

- **字帖数据**：本地静态 JSON + 图片（不设后端）
- **用户数据**：浏览器 LocalStorage（仅存历史记录）
