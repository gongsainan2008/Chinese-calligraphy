# 书法练习网站 - 技术方案

## 项目概述
- **类型**：Web 应用（书法字帖学习 + 拍照对比 + AI评分）
- **目标用户**：书法爱好者、初学者
- **开发方式**：个人开发

---

## 技术栈

| 层级 | 技术选择 |
|------|---------|
| 前端 | Next.js 14 (App Router) + Tailwind CSS |
| 后端 | Next.js API Routes |
| 数据库 | SQLite (轻量) 或 PostgreSQL |
| 存储 | 腾讯云 COS |
| 部署 | 腾讯云轻量服务器 + Nginx |
| AI | 腾讯云 TI-ONE（图像对比/评分） |

---

## 功能模块

### 第一阶段：MVP
1. **字帖库**
   - 分类展示：楷书、行书、隶书、草书、篆书
   - 每篇字帖：高清大图 + 临摹要点（文字说明）
   - 数据存储在数据库中，图片存 COS

2. **用户系统**
   - 注册/登录（邮箱 + 密码）
   - 每日打卡记录

3. **作品上传**
   - 拍照上传练习作品
   - 关联到对应字帖

### 第二阶段
4. **拍照对比**
   - 用户上传作品后，与原帖叠加显示
   - 透明度滑块调节

5. **AI 评分**
   - 调用腾讯云 TI-ONE 图像分析 API
   - 返回相似度评分 + 改进建议

## 数据库设计

### users 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| email | TEXT | 唯一 |
| password_hash | TEXT | 加密存储 |
| created_at | DATETIME | 注册时间 |

###字帖表 (calligraphies)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| title | TEXT | 标题（如：欧阳询《九成宫》） |
| category | TEXT | 楷书/行书/隶书/草书/篆书 |
| image_url | TEXT | COS 图片链接 |
| description | TEXT | 临摹要点 |
| created_at | DATETIME | 添加时间 |

### 作品表 (practices)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| user_id | INTEGER | 外键 → users |
| callig_id | INTEGER | 外键 → calligraphies |
| image_url | TEXT | 用户作品 COS 链接 |
| score | INTEGER | AI 评分（0-100） |
| ai_feedback | TEXT | AI 改进建议 |
| created_at | DATETIME | 练习时间 |

### 打卡表 (checkins)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| user_id | INTEGER | 外键 |
| date | DATE | 日期 |
| callig_id | INTEGER | 练了哪个字帖 |

## 部署步骤

1. **服务器**：腾讯云轻量服务器（2C2G）
2. **域名**：备案后解析
3. **Nginx**：反向代理到 Next.js
4. **PM2**：进程管理
5. **SSL**：Let's Encrypt 免费证书

---

## AI 评分方案

腾讯云 TI-ONE 或 Cloud API：

1. **图像相似度**：对比用户作品与原帖
2. **笔画评估**：检测笔画完整性、位置准确性
3. **返回**：
   - 相似度分数（0-100）
   - 具体改进建议（如：""横画倾斜"、"结构偏左"）
